ЧТО ЗАЛИВАТЬ НА ХОСТИНГ — ПРОЧТИТЕ 30 СЕКУНД

В этой папке лежит ОДИН архив. Для SpaceWeb (PHP-хостинг) нужен он:

    astra-pearl-php.zip   ≈ 0,7 МБ   ← берём этот файл и заливаем в public_html

Других сборок здесь нет: версия без кабинета и серверная версия на Node.js
из репозитория убраны, чтобы случайно не залить не то.

ВАЖНО: не заливайте на хостинг сам репозиторий (архив с GitHub «Code → Download ZIP»).
В нём исходный код: src, src-static, scripts, tests, tools, package.json.
Хостинг с ним сайт не покажет — нужен именно файл astra-pearl-php.zip из этой папки.

ПОРЯДОК ДЕЙСТВИЙ КРАТКО
1. Скачайте astra-pearl-php.zip на компьютер.
2. Панель SpaceWeb → Файловый менеджер → public_html.
3. Удалите стандартные index.html и .htaccess хостинга (если есть).
4. Загрузите zip в public_html → «Распаковать» в текущую папку → удалите zip.
5. Проверьте: index.html, api/, cabinet/, config.php лежат ПРЯМО в public_html.
6. Папка data → права 775.
7. Откройте https://ваш-домен/setup.php — там два шага в браузере:
   кнопка «Создать config.php» и пароль (хеш запишется сам).
   После этого удалите setup.php.
8. Откройте https://ваш-домен/check.php — страница покажет, что осталось сделать.
9. config.php и папку data/ НЕ удаляйте при обновлениях: в архиве нет config.php,
   поэтому распаковка нового архива не сбрасывает пароль и не трогает заявки.

ВХОД В КАБИНЕТ
- кнопка «Войти» в шапке сайта или адрес https://ваш-домен/cabinet/index.php
- логин: Adelina
- пароль: astrolog
Вход работает сразу после распаковки архива — даже если config.php ещё не создан.
В кабинете будет напоминание сменить пароль: задайте свой на setup.php.
Когда свой пароль задан, выключите вход по умолчанию — в config.php поставьте
'allowDefaultLogin' => false (в блоке 'security'). Тогда подходит только ваш пароль.
Если кабинет снова просит пароль после входа — откройте check.php, строка «Сессии входа».

ЧТО МОЖНО ПОМЕНЯТЬ БЕЗ ПРОГРАММИСТА (файл config.js рядом с index.html)
- siteName, logoText — название сайта;
- brandTitle — полное название («Драгоценная жемчужина души»);
- manifesto — тексты блока о жемчужине души на главной;
- invite.delayMs — через сколько секунд показывать окно с формой (40000 = 40 с);
- contacts — Telegram и почта для заявок.
Фон сайта: images/pearl-background.jpg (компьютер) и images/pearl-background-mobile.jpg
(телефон). Загрузите свою картинку с тем же именем — фон сменится.

Подробно, с проверками и разбором ошибок: docs/UPLOAD-SPACEWEB.md в репозитории.
Внутри архива есть такой же краткий README.txt — он всегда под рукой на хостинге.
