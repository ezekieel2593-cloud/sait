ЧТО ЗАЛИВАТЬ НА ХОСТИНГ — ПРОЧТИТЕ 30 СЕКУНД

В этой папке лежат ТРИ разных архива. Для SpaceWeb (PHP-хостинг) нужен ОДИН:

    astra-pearl-php.zip   ≈ 0,5 МБ   ← берём этот файл и заливаем в public_html

Остальные два вам не нужны:
    astra-pearl-static.zip    ≈ 0,4 МБ  — версия без кабинета и без сохранения заявок
    astra-pearl-hosting.zip   ≈ 14 МБ   — серверная версия на Node.js, для shared-хостинга не подходит

ВАЖНО: не заливайте на хостинг сам репозиторий (архив с GitHub «Code → Download ZIP»).
В нём исходный код: src, src-static, scripts, tests, tools, package.json.
Хостинг с ним сайт не покажет — нужен именно файл astra-pearl-php.zip из этой папки.

ПОРЯДОК ДЕЙСТВИЙ КРАТКО
1. Скачайте astra-pearl-php.zip на компьютер.
2. Панель SpaceWeb → Файловый менеджер → public_html.
3. Удалите стандартные index.html и .htaccess хостинга (если есть).
4. Загрузите zip в public_html → «Распаковать» в текущую папку → удалите zip.
5. Проверьте: index.html, api/, cabinet/, config.php лежат ПРЯМО в public_html.
6. Папка data → права 775.
7. Откройте https://ваш-домен/check.php — страница покажет, что осталось сделать.
8. Пройдите setup.php, вставьте хеш в config.php, удалите setup.php.

Подробно, с проверками и разбором ошибок: docs/UPLOAD-SPACEWEB.md в репозитории.
Внутри архива есть такой же краткий README.txt — он всегда под рукой на хостинге.
