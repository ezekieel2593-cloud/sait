# Статическая версия (заливка по FTP)

Версия для хостингов без Node.js: PHP-хостинг, shared-хостинг, GitHub Pages, Netlify, любой
FTP-доступ. Всё считается в браузере, сервер не нужен.

## Сборка

```bash
npm run build:static
# или с адресом сайта для sitemap/robots:
STATIC_SITE_URL=https://example.com npm run build:static
```

Результат: `release/static/` и архив `release/astra-pearl-static.zip` (≈0,8 МБ).

## Установка

1. Распакуйте архив и залейте **содержимое** папки в корень сайта по FTP
   (`public_html`, `www`, `htdocs`) — так, чтобы `index.html` оказался в корне.
2. Откройте на хостинге `config.js` и заполните:
   - `siteUrl` — адрес сайта (для canonical и карты сайта);
   - `contacts.telegram` — ник или ссылка (`my_nick` или `https://t.me/my_nick`);
   - `contacts.email` — почта для заявок;
   - `specialist` — имя, описание, путь к фото (файл положите в `images/`);
   - `services.priceNote`, `services.turnaround` — стоимость и сроки, если хотите их показывать;
   - `reviews` — только настоящие отзывы, иначе оставьте пустой массив.
3. Обновите страницу с очисткой кэша (Ctrl+F5).

Домен в `sitemap.xml` и `robots.txt` генерируется при сборке; если собирали без
`STATIC_SITE_URL`, замените `example.com` в этих двух файлах вручную.

## Состав архива

| Файл | Назначение |
| --- | --- |
| `index.html`, `astrology.html`, `matrix.html`, `full-reading.html`, `privacy.html`, `terms.html` | страницы (метатеги прописаны в HTML) |
| `app.js` | React-приложение и движки расчётов (`astro-v1`, `matrix-22-v1`) |
| `styles.css` | дизайн-система (Tailwind) |
| `fonts/` | локальные шрифты, без внешних CDN |
| `images/` | OG-картинка, favicon, плейсхолдер фото |
| `config.js` | настройки сайта — правится на хостинге |
| `404.html`, `.htaccess` | страница 404 и кэширование для Apache |
| `robots.txt`, `sitemap.xml` | индексация |
| `README.txt` | короткая инструкция для владельца |

## Что работает и чего нет

Работает:
- расчёт натальной карты в браузере: планеты, знаки, асцендент, дома, аспекты, исторические часовые пояса;
- разбор всех 12 домов: знак на куспиде, управитель и его дом, планеты внутри дома, аспекты к ним;
- гайды по энергиям Матрицы: несколько открыто, остальные — после запроса контактов;
- отдельная страница «Гайд по 22 энергиям» (`guide.html`): спорт, таланты, задача души, работа;
- отдельная страница «Чакры» (`chakras.html`): семь чакр, баланс и дисбаланс, практики, связь со схемой;
- PDF-гайд по энергиям собирается прямо в браузере (без сервера и внешних библиотек);
- расчёт Матрицы судьбы (22 аркана);
- открытая часть расшифровки и честно обозначенная закрытая часть;
- заявка: форма собирает готовый текст, кнопки открывают диалог в Telegram или письмо в почтовом клиенте;
- ссылка на результат: данные рождения кодируются в query-параметрах, результат воспроизводится при открытии.

Не работает (нужен сервер):
- кабинет специалиста, вход, статусы заявок, внутренние заметки;
- хранение заявок и расчётов в базе, журнал уведомлений и ретраи;
- автоматические уведомления в Telegram/MAX/SMTP (в статической версии отправку инициирует сам клиент);
- правка базы знаний и настроек из кабинета (настройки — в `config.js`).

## Ограничения и честность

Статическая версия не делает вид, что заявка «сохранена на сервере»: текст формы формируется
на устройстве пользователя, показывается целиком и отправляется только по его действию.
Формулировки на сайте это прямо объясняют.

Персональные данные не покидают браузер: расчёт выполняется локально, данные рождения попадают
только в адресную строку результата.

## Проверка после заливки

1. Главная открывается со стилями и шрифтами.
2. Матрица для 23.06.1992: центр — 10 (Колесо Фортуны).
3. Натальная карта: Лондон, 01.01.2000, 12:00 — Солнце 10°22′ Козерога, асцендент 24°01′ Овна.
4. Заявка: заполните поля — появится текст, кнопка «Открыть Telegram» ведёт в ваш диалог.
5. `/404.html` открывается при вводе несуществующего адреса (на Apache — из-за `.htaccess`).
