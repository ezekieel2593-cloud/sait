# Методика расчётов

Документ фиксирует, что именно считает сервис, какие параметры используются, какие
утверждения являются астрономическими фактами, а какие — эзотерическими трактовками,
и в чём ограничения результата.

Все расчёты выполняются на сервере. Версия алгоритма сохраняется вместе с результатом,
поэтому старые результаты можно воспроизвести: `astro-v1`, `matrix-22-v1`.

---

## 1. Натальная карта (`astro-v1`)

### Параметры (фиксированы версией)

| Параметр | Значение |
| --- | --- |
| Зодиак | Тропический, эклиптика даты |
| Эфемериды | `astronomy-engine` 2.1 (VSOP87 для планет, ELP2000 для Луны) |
| Система домов | Placidus по умолчанию, доступны равные дома и Whole Sign (настраивается) |
| Орбисы | соединение 8°, трин 7°, квадрат 6°, оппозиция 6°, секстиль 4° |
| Планеты | Солнце, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Плутон |
| Время | Исторические часовые пояса и переходы на летнее время (IANA tz), включая советский декретный час |

### Что считается

1. **Момент рождения → UTC.** Местное время переводится в UTC с учётом правил часового
   пояса на конкретную дату (а не текущего смещения). Пример: Москва, 14.07.1985, 03:40 —
   летнее время UTC+4, следовательно 23:40 UTC 13 июля.
2. **Положения планет.** Геоцентрические эклиптические долготы на юлианскую дату рождения.
   Ретроградность определяется по знаку суточной скорости.
3. **Асцендент и MC.** Рассчитываются из местного звёздного времени и широты места.
4. **Дома.** Куспиды по выбранной системе. Плацидус находится численно (сканирование
   эклиптики с уточнением бисекцией); на приполярных широтах, где Плацидус не определён,
   используется равнодомная система, и в `warnings` добавляется пояснение.
5. **Аспекты.** Пары планет в пределах орбисов с указанием расхождения.
6. **Распределения** по стихиям и крестам, фаза Луны.

### Если время рождения неизвестно

Асцендент, MC и дома **не выдаются как достоверные**: `ascendant = null`, `houses = null`,
планеты получают `house = null`, в `warnings` добавляется пояснение. В интерфейсе такой
результат помечен, а разделы, зависящие от домов, не строятся.

Точность времени `approx` (примерное) сохраняется в карте и отмечается в тексте, но расчёт
выполняется по указанному времени.

### Контрольные значения (закреплены тестом `tests/astronomy.test.ts`)

Лондон, 2000-01-01, 12:00 UT (51.5072, −0.1276):

| Показатель | Значение |
| --- | --- |
| Солнце | 10°22′ Козерога (280.3687°) |
| Луна | 13°19′ Скорпиона (223.3239°) |
| Асцендент | 24°01′ Овна |
| MC | 9°30′ Козерога |
| Сатурн | ретроградный |

## 2. Матрица судьбы (`matrix-22-v1`)

### Правило редукции

`reduce22(n)`: число приводится к диапазону 1–22 сложением цифр; 0 → 22, 22 сохраняется.
Версия зафиксирована как `REDUCTION_RULE = "digit-sum"`. Другие школы используют вычитание
22 вместо сложения цифр — это осознанный выбор версии, а не универсальная норма.

### Позиции

Для даты рождения (день `d`, месяц `m`, год `y`):

- **A** = reduce22(d) — характер и точка входа;
- **B** = m — таланты и ресурс;
- **C** = reduce22(сумма цифр года) — родовые программы;
- **D** = reduce22(A + B + C) — карма и социальные задачи;
- **Центр** = reduce22(A + B + C + D) — комфорт, предназначение;
- **Родовой квадрат** — четыре угла, каждый = reduce22(сумма двух ближайших углов диагонали);
- **Сила рода** = reduce22(сумма четырёх углов);
- **Деньги**: вход = reduce22(C + Центр), середина = reduce22(вход + общая точка);
- **Отношения**: вход = reduce22(D + Центр), середина = reduce22(вход + общая точка);
- **Общая точка** каналов = reduce22(вход денег + вход отношений);
- **Ось таланта**: личные таланты = reduce22(B + Центр), развитие таланта = reduce22(B + личные таланты);
- **Ось личности**: личная опора = reduce22(A + Центр), опыт личности = reduce22(A + личная опора);
- **Энергия года** = reduce22(d + m + сумма цифр года).

### Линия жизни по кругу

Углы квадратов идут по кругу шагом 10 лет: A — рождение, родовой угол — 10 лет, B — 20,
следующий родовой угол — 30, C — 40, родовой угол — 50, D — 60, последний родовой угол — 70,
дальше круг начинается заново. Внутри каждого десятилетия:

- **середина (5 лет)** = reduce22(угол + следующий угол);
- **2,5 года** = reduce22(угол + середина);
- **7,5 года** = reduce22(середина + следующий угол).

На схеме это 32 значения по краю восьмиугольника и подписи возраста; промежуточные точки
(2,5 и 7,5) подписаны числом без возраста, чтобы не перегружать край. Правило и последовательность
углов взяты из описания методики (см. `src/lib/knowledge/sources.ts`), поэтому линия жизни —
расчётная величина, а не декоративные числа.

Порядок арканов — марсельский: 8 — Справедливость, 11 — Сила.

### Контрольный пример (закреплён тестом `tests/matrix.test.ts`)

23.06.1992: A = 5, B = 6, C = 21, D = 5, центр = 10; родовой квадрат 11 / 9 / 8 / 10,
сила рода 11; деньги 4 / 5; отношения 15 / 7; общая точка 19; личные таланты 16, развитие
таланта 22, личная опора 15, опыт личности 20; линия жизни начинается с 0 лет = 5, 5 лет = 16,
10 лет = 11, 20 лет = 6, 40 лет = 21, 60 лет = 5.

Расчёт детерминирован: случайных чисел нет, одна дата всегда даёт один результат.

## 3. База знаний и интерпретации

- Реестр источников: `src/lib/knowledge/sources.ts` — id, название, URL, издатель, дата
  проверки, пояснение. Источники не выдумываются: внешние ссылки ограничены реально
  использованными страницами, внутренние записи явно помечены как редакционные.
- Записи (`knowledge_entries`) содержат: показатель, краткую трактовку, плюсы, риски,
  рекомендации, методику, источник и версию. Тексты — оригинальные формулировки проекта,
  а не копии чужих материалов.
- Разделение понятий: астрономические данные (положения, дома, аспекты) — расчётные факты;
  значения арканов и трактовки — эзотерическая традиция, они подаются как традиция,
  а не как доказанное знание.
- Бесплатная часть ограничена на сервере (`freeResult` в настройках). Закрытые разделы
  уходят в браузер только заголовками, текстов не содержит ни HTML, ни API.

### Разбор домов натальной карты (`astrology.ts`, `houseSections`)

Каждый из 12 домов получает карточку из четырёх слоёв, а не общую фразу о сфере:

1. **Сфера дома** — краткая трактовка из базы знаний (`house1`…`house12`).
2. **Куспид** — знак на начале дома и трактовка этого знака: через что раскрывается сфера.
3. **Управитель** — планета-хозяин знака куспида (`SIGNS[].ruler`), её тема, знак и дом
   в конкретной карте, ретроградность; если время рождения неизвестно, дома не строятся
   и это указано явно.
4. **Планеты в доме** — каждая планета со знаком, своей темой и трактовкой знака, плюс
   до двух самых точных аспектов к планетам этого дома (орб в градусах).
5. **Плюсы, зоны внимания и рекомендации** складываются из куспида и планет дома.

Аспекты в разборе не обрезаются до шести: по умолчанию `maxAspects` = 24, то есть в карту
попадают все аспекты в допустимых орбисах, а их полный список выводится в блоке
«Планеты, дома и аспекты». Дома остаются закрытыми разделами для гостя и открываются
владельцу (и по заявке) — ограничение задаётся `freeResult.astrologyCardCount`.

### Гайд по 22 энергиям (`src/lib/knowledge/practical.ts`, `general-guide.ts`)

К каждой из 22 энергий — девять бытовых ответов: каким видят другие, таланты, кармическая
задача, спорт, утро, ресурс, расслабление, работа; плюс деньги и отношения из базы знаний
аркана. Это общий справочник: он не привязан к дате рождения и открыт на отдельной странице
`guide.html`. Персональные гайды (`interpretation/guides.ts`, `simple.ts`) собираются из тех же
текстов, но только для энергий конкретной схемы.

У каждого ответа есть объяснение «почему так» (`why` в `PracticalText`): оно показывает, из какой
черты энергии вырос совет. Плюс к этому у каждой энергии есть `logic` — одна-две фразы о внутренней
логике аркана, из которой разворачиваются все остальные советы. На странице `guide.html` логика
вынесена отдельным блоком под сутью, а «почему так» идёт мелким текстом под каждым аспектом;
в PDF эти же объяснения печатаются под ответом.

Ответы подаются как бытовые ориентиры традиции, а не предписания: спорт и режим — примеры,
а не медицинские рекомендации. Объяснение «почему» тоже не диагноз и не прогноз: это связка
«черта энергии → следствие в быту», которую читатель может примерить на себя.

### Гайды по энергиям (`src/lib/knowledge/guides.ts`)

На каждую из 22 энергий есть практический гайд: суть, как энергия проявляется в обычной
жизни, четыре шага «что делать», практика на неделю, признак «энергия работает в плюсе»
и два пункта «чего избегать». Гайд привязывается к схеме человека: если энергия стоит
в нескольких точках (например, в центре и в канале денег), гайд один, а места перечислены
в подзаголовке.

Гостю открыто `freeResult.matrixGuideCount` гайдов (по умолчанию 2), остальные видны
заголовками и первой фразой сути. Владелец видит все гайды и может собрать PDF:
`src/lib/pdf/` — минимальный генератор PDF (страницы A4, переносы по ширине, встроенный
TrueType с кириллицей, таблица ToUnicode), без внешних библиотек.

## 4. Ограничения

- Астрология и Матрица судьбы не имеют научного подтверждения; сервис не утверждает
  обратного и не заменяет медицинскую, юридическую или финансовую консультацию.
- Точность натальной карты зависит от точности времени рождения: при неизвестном времени
  дома и асцендент недостоверны и не выдаются.
- Исторические часовые пояса до 1970-х годов местами неоднозначны; для спорных дат
  результат сопровождается предупреждением.
- Координаты населённых пунктов берутся из локального справочника; при необходимости
  можно указать координаты вручную.
