# Публичный портал cosmorox.ru

## Сборка и размещение

- `npm run build` создаёт `dist/`: многостраничный React/TypeScript сайт, Vite-бандлы с разделением маршрутов, SEO HTML и небольшие PHP endpoints для shared-хостинга.
- На Cloud4box загружается содержимое `dist/` в `public_html`; Node.js на сервере не нужен.
- `npm run build:php` создаёт основной deploy-архив `download/astra-pearl-php.zip` и остаётся сборкой, используемой FTP workflow.
- `npm run dev` относится к серверной Next.js редакции; для статического портала используйте production `dist/` после `npm run build`.

## Модули

- `src/features/astrology/` — фасад астрологического расчётного движка и транзитов.
- `src/features/matrix/` — фасад расчёта 22 энергий и чакр.
- `src/features/cabinet/` — профили/история в `localStorage`, витрина, консультационная форма, прогноз и блог.
- `src/services/api.ts` — граница API. Секреты оплаты и Telegram остаются на сервере; кнопка покупки не создаёт фиктивный платёж.
- `src-static/` — публичные страницы и калькуляторы. Vite загружает чанки страниц по требованию.

## Состояние подключений

- Личные профили и расчёты сохраняются локально в браузере и не синхронизируются между устройствами.
- Заявка отправляется через `api/lead.php`, если пакет собран с PHP API; в режиме без backend интерфейс честно сообщает, что заявка не отправлена.
- ЮKassa и автоматическая генерация персональных PDF не подключены. PDF-кнопка в кабинете создаёт демонстрационную HTML-заготовку для печати в PDF, не готовый персональный разбор.
- Прогноз считает транзиты к указанной натальной карте. Метрика баланса — отношение числа аспектов в выборке, не вероятность событий. Лунная фаза на виджете оценивается приблизительно.
