# Astra Pearl — астрология и Матрица судьбы

Рабочий веб-сервис: бесплатный расчёт натальной карты и Матрицы судьбы, содержательная
бесплатная расшифровка, заявка на полный разбор и закрытый кабинет специалиста, где
доступны полные расчёты, статусы заявок, внутренние заметки и настройки сайта.

Всё считается на сервере по фиксированным алгоритмам с версиями (`astro-v1`,
`matrix-22-v1`). Случайных чисел и «демо-результатов» нет: один и тот же набор данных
всегда даёт один и тот же результат.

## Что уже работает

**Публичная часть**

- `/` — главная с описанием двух направлений и честным разделением бесплатной и платной части.
- `/astrology` — многошаговая форма рождения (дата, точность времени, поиск города с координатами
  и часовым поясом), расчёт натальной карты.
- `/matrix` — расчёт Матрицы судьбы по дате рождения (22 аркана).
- `/astrology/result/[id]`, `/matrix/result/[id]` — результат: SVG-колесо/диаграмма, таблицы,
  бесплатные разделы расшифровки, закрытые разделы, форма заявки на полный разбор.
- `/full-reading` — описание полного разбора, состава и формата.
- `/privacy`, `/terms` — политика обработки данных и условия использования.
- `/sitemap.xml`, `/robots.txt`, OG-разметка, canonical, семантическая вёрстка.

**Кабинет специалиста** (закрытая зона, `noindex`, вход по паролю)

- `/specialist/login` — серверная авторизация, scrypt-хеши, лимит попыток и блокировка.
- `/specialist` — обзор: счётчики заявок, последние заявки, состояние каналов уведомлений, объём базы знаний.
- `/specialist/leads` — поиск (по имени, контакту, номеру), фильтры по статусу и направлению,
  сортировка, пагинация.
- `/specialist/leads/[id]` — карточка заявки: данные клиента, вопрос, полный расчёт (карта или матрица),
  смена статуса, внутренние заметки, история изменений, журнал уведомлений, копирование текста разбора,
  повторная отправка уведомлений, обезличивание персональных данных.
- `/specialist/settings` — настройки без правки кода: название и описание, специалист и фото,
  контакты, услуги и цены, объём бесплатной части, методика, отзывы, FAQ, сроки хранения данных,
  смена пароля, состояние интеграций.
- `/specialist/knowledge` — реестр источников и записей базы знаний с методикой и версией.

**API** (все ответы содержат `apiVersion: "1"`, см. [docs/API.md](docs/API.md))

- `GET /api/geo/search?q=…` — поиск города с координатами и часовым поясом.
- `POST /api/charts/astrology` — расчёт натальной карты.
- `POST /api/charts/matrix` — расчёт Матрицы судьбы.
- `GET /api/charts/[id]` — чтение сохранённого расчёта (только бесплатная часть интерпретации).
- `POST /api/leads` — заявка на полный разбор.
- `/api/specialist/*` — закрытые маршруты кабинета, требуют сессию.

## Стек

- Next.js 16 (App Router, TypeScript), React 19, Tailwind CSS v4.
- `astronomy-engine` — эфемериды (VSOP87/ELP2000), расчёт домов и асцендента.
- `node:sqlite` — хранилище (заявки, расчёты, настройки, база знаний, журнал уведомлений).
- Zod — валидация, `nodemailer` — e-mail уведомления, `vitest` — тесты.

## Быстрый старт

Требуется Node.js 22.5+ (используется встроенный `node:sqlite`).

```bash
npm install
cp .env.example .env.local      # заполните AUTH_SECRET и адрес сайта
npm run db:migrate              # создаёт ./data/app.db
npm run db:seed                 # услуги, источники и база знаний
npm run create-specialist -- --email you@example.com --name "Имя" --password 'длинный-пароль'
npm run dev                     # http://localhost:3000
```

Полезные команды:

```bash
npm run db:migrate                  # применить схему (идемпотентно)
npm run db:seed                     # услуги, источники, записи базы знаний
npm run create-specialist -- --list # список аккаунтов
npm run create-specialist -- --email a@b.c --reset-password
npm test                            # vitest: расчёты, валидация, заявки, API
npm run build && npm start          # production-сборка
npx tsc --noEmit                    # проверка типов
```

## Структура проекта

```
src/
  app/                     маршруты (публичная часть в группе (public), кабинет в specialist)
  components/              интерфейс: site, forms, charts, result, cabinet
  lib/
    astronomy/             часовые пояса, города, движок натальной карты (astro-v1)
    matrix/                движок Матрицы судьбы (matrix-22-v1)
    knowledge/             источники, записи, доступ к базе знаний
    interpretation/        сборка расшифровок из базы знаний
    repositories/          доступ к данным: расчёты, заявки, услуги
    notifications/         диспетчер уведомлений с журналом и ретраями
    services/              сценарии расчёта (API и страницы используют их)
    db.ts, auth.ts, ...    схема, авторизация, настройки, валидация, лимиты
scripts/                   миграция, сидирование, создание специалиста
tests/                     vitest: расчёты, валидация, заявки, API
docs/                      методика, API, интеграции, деплой
```

Бизнес-логика отделена от интерфейса: страницы и API вызывают `src/lib/services/*`,
поэтому те же сценарии переиспользуются мобильным приложением.

## Лицензия и данные

Тексты интерпретаций — оригинальные формулировки проекта; внешние источники перечислены
в реестре (`src/lib/knowledge/sources.ts`) с URL и датой проверки. Персональные данные
клиентов хранятся только для обработки заявки и удаляются по запросу или по сроку хранения
из настроек.
